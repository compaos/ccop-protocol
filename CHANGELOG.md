# Changelog

All notable Protocol changes are documented here.

## [Unreleased]

- Adopted **CCOP — Company Coordination and Operations Protocol** as the implementation-neutral project name.
- Established the independent, implementation-neutral repository structure.
- Separated semantic specifications, versioned schemas, conformance assets, and reference cores.
- Added governance, contribution, security, compatibility, and RFC policies.
- Locked `Task` as the canonical work object and documented Signal as future, non-normative guidance.

## [0.5.3] - 2026-08-16

- Published the v0 schema-lock reference-core baseline.
- Added JSON Schema Draft 2020-12 canonical object definitions and normative registries.
- Added Python and TypeScript reference cores with cross-language differential vectors.
- Added the N1–N65 negative-conformance inventory and executable high-risk security checks.
